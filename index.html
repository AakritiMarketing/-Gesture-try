Honest note on scope: the "sign → speech" side here recognizes a small fixed set of hand shapes (open palm, fist, thumbs up, peace, pointing, OK, "I love you") using hand-landmark geometry, not full ASL/BSL grammar - real sign languages use motion, facial expression and sentence structure that a single static-pose classifier can't capture. The "speech → sign" side matches spoken keywords to those same hand shapes and plays them back as an icon + caption, not a realistic signing avatar. This is a working starting prototype, not a certified communication aid - treat it as a base to extend (e.g. train a proper gesture-sequence model, or license a real sign avatar library) rather than a finished accessibility product.
